# 🏛️ الدورة المحاسبية الكاملة — Full Accounting Cycle

نظام محاسبي مزدوج القيد بأساس الاستحقاق (Double-entry, Accrual basis) — قيد لكل
شركة (tenant) في الـ schema الخاص بها، متوازن دائمًا، ويولّد القوائم المالية
المعيارية.

## المكوّنات (Building blocks)

| النموذج | الغرض |
|---|---|
| `ChartOfAccount` | دليل الحسابات (أصول/خصوم/حقوق ملكية/إيرادات/مصروفات) |
| `FiscalYear` / `AccountingPeriod` | السنة المالية والفترات القابلة للإقفال |
| `JournalEntry` | قيد اليومية — مستند متوازن يجمع عدة سطور |
| `AccountingEntry` | سطر القيد (مدين/دائن) — دفتر الأستاذ العام |
| `TaxRate` | معدلات الضريبة وربطها بحساب الالتزام |

## محرّك الترحيل — `AccountingService`

كل حدث اقتصادي يتحوّل إلى `JournalEntry` متوازن. لو مجموع المدين ≠ الدائن يُرفض
الترحيل، فالأستاذ العام **متوازن دائمًا**. كل دالة **idempotent** (لا تُكرّر
ترحيل نفس المستند) وكل ترحيل داخل `savepoint` (لا يبقى قيد نصف مكتمل).

### خريطة القيود (Posting map)

```
فاتورة مبيعات (استحقاق)          مقبوضات من عميل
  مدين: المدينون (بالضريبة)        مدين: النقدية/البنك
    دائن: إيرادات المبيعات            دائن: المدينون
    دائن: ض.ق.م المستحقة
  مدين: ت. البضاعة المباعة        فاتورة مشتريات (استحقاق)
    دائن: المخزون                   مدين: المخزون
                                      دائن: الدائنون
مدفوعات لمورد                   مصروف نقدي مباشر
  مدين: الدائنون                   مدين: المصروف / دائن: النقدية
    دائن: النقدية/البنك           إيراد نقدي مباشر
مردود مبيعات = عكس البيع          مدين: النقدية / دائن: إيرادات أخرى
إقفال الفترة: الإيرادات والمصروفات → ملخص الدخل → الأرباح المحتجزة
```

**النقطة الجوهرية:** الإيراد و تكلفة البضاعة يُعترف بهما وقت ترحيل الفاتورة
(استحقاق)، لا وقت التحصيل. لذلك البيع الآجل يظهر في الأستاذ العام كإيراد
وذمة مدينة فورًا، والتحصيل لاحقًا **يُسوّي الذمة فقط** (لا يُسجّل إيرادًا
مرة ثانية → لا ازدواج).

## القوائم المالية — `AccountingReportService`

- ميزان المراجعة (Trial Balance)
- دفتر الأستاذ لحساب واحد برصيد جارٍ (General Ledger)
- قائمة الدخل (Income Statement)
- الميزانية العمومية (Balance Sheet)
- قائمة التدفقات النقدية (Cash Flow)
- أعمار الذمم المدينة/الدائنة (AR/AP Aging)

## واجهات API (تحت `/api/v1/accounting/`)

| المسار | الوصف |
|---|---|
| `income-statement/?from=&to=` | قائمة الدخل |
| `balance-sheet/?as_of=` | الميزانية العمومية |
| `trial-balance/?as_of=` | ميزان المراجعة |
| `cash-flow/?from=&to=` | التدفقات النقدية |
| `general-ledger/<code>/?from=&to=` | أستاذ حساب |
| `aging/receivables/` `aging/payables/` | أعمار الذمم |
| `journal/?type=&from=&to=` | قيود اليومية |

الصلاحية: `admin` / `manager` / `accountant` فقط.

## إقفال الفترة (Period close)

من لوحة الأدمن → «الفترات المحاسبية» → إجراء «🔒 إقفال الفترات المحددة».
يُنشئ قيود الإقفال (تصفير الإيرادات والمصروفات في ملخص الدخل ثم ترحيل الصافي
للأرباح المحتجزة) ويمنع أي ترحيل لاحق داخل الفترة المقفلة.

## ضمانات السلامة (Integrity guarantees)

1. **التوازن**: لا يُرحَّل قيد غير متوازن (يُرفض على مستوى المحرك).
2. **الذرّية**: طرفا القيد داخل `savepoint` — إما الاثنان أو لا شيء.
3. **عدم التكرار**: idempotency لكل مستند (فاتورة/حركة).
4. **قفل الفترات**: لا ترحيل في فترة مُقفلة.
5. **العزل**: قيود كل شركة في schema مستقل تمامًا.
